# CodeAlpha Python Programming Internship

This repository contains the 3 Python tasks I completed during my CodeAlpha internship.

## Task 1: Hangman Game
A text-based Hangman game. The computer picks a random word from 5 predefined words, and the player guesses one letter at a time with a maximum of 6 wrong guesses.

**Run:**
```
cd Task1_Hangman
python hangman.py
```
**Concepts:** random, while loop, if-else, strings, lists

## Task 2: Stock Portfolio Tracker
Takes stock names and quantities from the user, calculates the total investment using a hardcoded price dictionary, and saves the report to `portfolio.txt`.

**Run:**
```
cd Task2_StockTracker
python Stock_Tracker.py
```
**Concepts:** dictionary, input/output, arithmetic, file handling

## Task 3: Email Extractor (Automation)
Reads `input.txt`, extracts all unique email addresses using regex, and saves them to `emails.txt`.

**Run:**
```
cd Task3_EMailExtractor
python Email.Extractor.py
```
**Concepts:** re (regex), file handling, set
